# COSMIC CRAFT // PRODUCTION CONTENT GLOSSARY
# Инструкция по структуре и управлению контентом лендинга (landing_preview.html / index.html)

Этот документ — ваш путеводитель по коду лендинга. Здесь зафиксировано, где находится каждый текстовый блок, заголовок, элемент интерфейса и путь к изображениям, чтобы при подготовке к продакшену вы могли точечно и безопасно менять контент.

---

## 1. СТРУКТУРНЫЕ БЛОКИ (Сверху вниз по странице)

### Блок А: Верхняя шапка (Header)
* **Расположение в коде:** Поиск по тегу `<header>` (примерно строка 210).
* **Что можно менять:**
  * Логотип / Название бренда: Текст `COSMIC CRAFT` (имеет JS-обработчик клика для звукового пасхалко-резонанса `playSecretSound()`).
  * Скругления и стили: Классы `rounded-2xl mx-2 sm:mx-4 mt-2 shadow-2xl`.

### Блок Б: Переключатель миров (Switcher Bar)
* **Расположение в коде:** Блок `<div class="sticky z-30 ..."` сразу под шапкой (строки 220–250).
* **Что можно менять:**
  * Названия кнопок миров: `<span class="...">Готика</span>`, `<span class="...">Посткап</span>`, `<span class="...">Хоррор</span>`, `<span class="...">HP & Craft</span>`.
  * Функция переключения: `onclick="setTheme('gothic' | 'postap' | 'horror' | 'arcane')"`.

### Блок В: Герой и витрина миров (Hero & Showcase)
* **Расположение в коде:** Секция `<section class="px-4 pt-10 ...">` и `<main>` (строки 250–290).
* **Динамические данные (берутся из объекта `scenes` в JavaScript):**
  * Тексты заголовков (`hero-title`, `hero-subtitle`), бейджи каталога (`badge-theme`), картинки витрин (`scene-img`), описание и код сцены. Все тексты и пути к фото меняются внутри объекта `scenes` (см. Раздел 2).

### Блок Г: Календарь мероприятий (CHRONICLES // CALENDAR)
* **Расположение в коде:** Блок с классом `CHRONICLES // CALENDAR` (сразу после витрины).
* **Что менять (даты и события):**
  ```html
  <div class="flex items-start justify-between pb-3.5 border-b border-white/10">
      <span class="font-mono font-bold current-accent-text tracking-wider">ДАТА (например, 12.10)</span>
      <span class="text-[#8E8B85] text-right font-light max-w-[240px]">Текст события или анонса дропа</span>
  </div>
  ```

### Блок Д: Философия крафта (PHILOSOPHY // CRAFT)
* **Расположение в коде:** Блок «Архитектура ручной работы».
* **Что менять:**
  * Заголовок и абзац текста о методах работы (3D-скульпт, ручная патина и сборка).

### Блок Е: Подвал и CTA (Call to Action)
* **Расположение в коде:** Нижняя премиальная плашка с кнопкой связи.
* **Что менять:**
  * Ссылка на Telegram-канал/менеджера: `href="https://t.me/cosmiccraft21"`.
  * Текст призыва к покупке или заказу кастома.

## 2. УПРАВЛЕНИЕ МИРАМИ И ТОВАРАМИ (Объект `scenes` в JS)

Все 4 мира (`gothic`, `postap`, `horror`, `arcane`) и их товары управляются через единый массив в секции `<script>` (строки ~350–530). 

### Структура каждого мира:
```javascript
gothic: {
    badge: "CATALOGUE № 01 // GOTHIC CRYPT",        // Верхний мини-бейджик
    title: "Артефакты темной эстетики",              // Главный заголовок мира
    subtitle: "Описание под заглавием...",          // Подзаголовок
    image: "gothic_altar.jpg",                      // Главное фото витрины мира
    code: "SCENE 01 // CRYPT ALTAR",                // Технический код сцены
    sceneTitle: "Gothic Altar & Occult Relics",     // Название инсталляции
    sceneDesc: "Инструкция для гостя...",           // Подсказка на табличке витрины
    
    // Список товаров (Хот-споты)
    hotspots: [
        {
            top: "28%", left: "41%",                // Координаты точки на фото в %
            title: "Черный кружевной чокер",          // Название товара во всплывашке
            desc: "Описание ручной работы...",        // Музейное описание
            price: "2 500 ₽",                       // Цена
            badge: "VICTORIAN CHOKER",              // Бейдж лота
            images: [                               // Галерея (до 3 фото: Анфас, Профиль, Бок)
                "gothic_altar.jpg",
                "фото_ракурс_2.jpg",
                "фото_ракурс_3.jpg"
            ]
        }
    ]
}
```
